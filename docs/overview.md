# Overview

**wp-module-survey** collects customer satisfaction feedback via surveys in the WordPress admin dashboard. It registers with the Newfold Module Loader. Used by wp-module-onboarding-data and other modules. No runtime Composer requires. Maintained by Newfold Labs. Distributed via Newfold Satis.
